# AI Agent Memory Hub deployment contract

When a user gives you this repository to deploy, read `INSTALL.md` completely before taking action. Prefer the ordinary web workbench without changing Agent rules. Read `docs/agent-deployment.md` only for optional managed-rule installation.

- Inspect first. Do not install software, create a Vault, or edit any Agent rule file during discovery.
- Run `python -B launch.py --check` first. After the user chooses trial or real work and necessary folders, configure and verify the authorized local workbench without requiring rule installation.
- Ask for explicit approval before applying the generated plan, especially before editing global rules.
- Preserve all user-authored rule content outside the managed block and keep the generated backup.
- Never copy an existing personal Vault, worklog, credential, token, cookie, or full connection string into this repository.
- Windows and macOS support the core and web workbench. The desktop application is Windows 10/11 only.
- Report commands run, files changed, verification results, backups, and unresolved prerequisites.
