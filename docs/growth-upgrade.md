# v0.3.0 统一升级清单

基线为公开版 v0.2.1。作者本地记忆中枢、独立工作台前端和公开产品并非同一目录的脱敏副本。

| 能力 | 本地原有 | v0.2.1 公开缺口 / 看板未接 | v0.3.0 交付 |
| --- | --- | --- | --- |
| 协议 | 完整协议和较新的精简适配 | 有协议文字，缺近期细节与共同执行层 | 3.3.0 通用协议；原 3.2.1 保留 |
| 触发/复盘 | 事件规则、字段及引用校验 | 无同源执行管线 | 共用 Module；未知/缺配/证据不足明确区分 |
| 任务身份 | 稳定任务和回执修订 | 每次关闭新 ID，反馈未关联 Episode | 新任务/接续/修订、请求幂等、旧基线拒绝；无身份不计独立支持 |
| 评估/月报 | 持久账本、人工区保护、去重 | 未集成 | 同源实现；回执数与任务数分离、跨月刷新 |
| 用户反馈 | 运行时反馈与工作循环两条既有路径 | 成果采用/修改不等于成长结果 | 回执/文件版本关联；显式观察；主反馈源触发；不自动晋升 |
| 方法 | 本地方法与高级 Policy 试点 | 能力地图人工成熟度不是自动复验 | 待复验候选与证据可见，保持权威层级分离 |
| 下一任务 | 完整编译器等本地试点 | 原有接续包未带成长状态 | 既有接续包增加成长状态和候选停止规则 |
| 派生保护 | 原始字节水印、原回执重放 | 未公开近期连续性逻辑 | 共用准入逻辑、源水印/状态哈希、失败 outbox 和原回执重放 |
| 默认部署 | 多工具本地规则与试点配置 | 普通公开安装不应强制模型/规则 | 保持轻模式；记录需显式启用，运行时在正式库和源码外 |

本版**没有公开/激活**完整 World Fact、L2/L3 Policy 运行时与 TaskMemoryPacket 编译器。这些不是普通接续包的同义词，仍有独立的路径、并发、authority 与多项目验收前置条件。

## 复验层次

1. 接口与负例：普通任务零评审、未知事件、坏哈希、越权引用、重复任务、无证据/身份未决历史、源漂移、失败恢复、人工区保护。
2. 业务闭环：真实代码配隔离合成库，执行收工→反馈→待复盘→评估/月报→接续，不把合成样本当自然效果。
3. 界面：真实浏览器保存、重载、1440/1280/390 宽度、溢出和运行错误；保留已有生命周期与版本保护。
4. 模型行为：未见变体、新会话、实际入口及配置记录。CLI、Desktop GUI、其他 Agent 分开，不用结构测试替代行为验证。
5. 发行：清洁解压目录、独立 Vault/运行时、升级保留和包内指纹；源码推送不是所有平台安装通过。

自然任务中的遗漏率、无效打扰和长期认知增益仍需持续记录。无独立判断时不给总体成功率；无评审适配器时保留待处理，不伪装完成。

本版已实际执行的测试、浏览器、清洁环境升级与新变体抽验见 [v0.3.0 验收范围](validation-v0.3.0.md)。未验项不合并到“已通过”。
