# 虚拟数据交互体验

发行版中的 `AI-Personal-Workbench-Demo-v0.2.1.html` 将实际工作台的CSS和界面脚本内嵌，另加独立的浏览器虚拟数据适配器。正式工作台不加载这个适配器，也不会将它的数据导入真实记忆库。

页面有7个虚拟项目、三类共7篇虚拟原文。所有数字、回执、成果与反馈均为虚构样例，不能作为业务效果、真实使用人数或检索准确率的证据。

| 能力 | 在单文件体验中的表现 | 真实使用 |
| --- | --- | --- |
| 当前工作 | 摘要、建议、人工调整、变化确认与重点项目 | 读取本人已接入的真实项目与正式回执 |
| 项目与总账 | 多个状态、范围守恒、确认队列、活动线索与新鲜度提示 | 按真实来源核对，不以活动代替验收 |
| 知识检索 | 三类虚拟资料、通用文字匹配、范围筛选、原文查看、加入与移除接续资料 | 完整包检索已接入Markdown，可选本地语义模型 |
| 接续 | 生成、审阅、复制、下载Markdown | 由现有Agent读取Skill并执行明确授权的工作 |
| 成果与版本 | 模拟交付，查看原文，采用、修改、暂缓与用途区分 | 真实文件路径、SHA256及正式验收记录 |
| 文件保护 | 模拟已采用文件改变，拒绝沿用失效版本 | 检查真实文件是否变化或丢失 |
| 生命周期 | 暂停、结束归档、恢复、刷新保留与重置 | 决定持久写入本地账本 |
| 使用记录与方法 | 保存虚拟记录，显示能力证据阶段 | 需要真实原始凭据及独立复验 |

原文和成果在页内展示虚拟文本，不会启动本机应用。“模拟Agent交付”只增加虚拟版本，不调用模型或其他Agent。暂缓日期只是本页记录，不提供操作系统或后台通知。

脚本拦截工作台的虚拟接口请求，未配置真实后端连接；浏览器允许时使用独立localStorage键保存演示状态。存储不可用时保留本次内存交互并提示刷新重置。复制受浏览器剪贴板权限限制，可使用文本框手动复制；接续包也可下载。没有外部脚本、字体或样式依赖，点击下载部署包链接会前往GitHub。

可从源码重新生成：

```powershell
python -B scripts/build_standalone_demo.py --output "体验.html"
```

内置验收浏览器限制file协议，自动浏览器验收通过只提供这份虚拟页面的本机HTTP预览完成，不能将其记为已经在该浏览器验证了file协议。独立构建检查确认资源全部内嵌，JavaScript回归覆盖虚拟状态、版本保护和无外部接口调用。真实本机部署与升级请从 [INSTALL.md](../INSTALL.md) 开始。
