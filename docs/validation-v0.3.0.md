# v0.3.0 验收范围与限制

2026-11-02，Windows 11 / Python 3.12。测试使用隔离合成库，不包含作者正式库、私人规则、模型凭据或真实业务结果。

| 层次 | 实际证据 | 结论边界 |
| --- | --- | --- |
| 公开代码回归 | 168 tests、2 subtests 通过 | 包含触发/证据/身份、幂等、旧修订拒绝、源漂移、写前及写后异常回滚、缺配与恢复 |
| 同源核心 | 7 个模块文件与维护源逐字节一致，导出清单可核验 | 本地专用脚本保留适配；不是两个算法分支 |
| 清洁环境 | 无 pip / 第三方包的独立 venv；setup→project→close→prompt→report→replay | 无评审时保留 pending；没有内置云模型调用 |
| 旧包升级 | 实际 v0.2.1 ZIP，经来源校验；升级保留7项配置/项目/回执/反馈文件原始字节 | 保留源码备份；定制源码仍需自行合并，不自动删除新增文件回滚 |
| 真实浏览器 | 候选发行包服务；11项断言；明确漏判保存→刷新仍在→待复盘；1440/1280/390 无页面溢出，pageerror=0 | Edge 无头浏览器，合成样本，不是用户的自然使用效果 |
| 协议行为抽验 | 原生 Codex CLI 独立 ephemeral 会话；第一组3个完成变体命中，另1次超时不可判；关闭记忆的第二组新变体1个命中 | 按冻结条件由主 Agent 判定，非独立盲评；两组不同配置，不合并总体成功率；未用原题重跑覆盖超时 |

Windows 原生桌面壳 GUI、macOS/Linux、其他 Agent 的行为加载与实际任务仍需对应环境复验。CLI 的文本注入不证明 Desktop GUI 实际加载，字段合法也不证明长期认知增益。

尚未观察的结果保持 unknown，采用不等于验证，方法候选不等于正式 Policy。完整 World Fact / L2-L3 Policy / TaskMemoryPacket 运行时仍是本地独立试点，不属于本版发行承诺。
